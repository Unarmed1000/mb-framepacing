# Vocabulary

mb-framepacing uses the vocabulary of [Intel PresentMon](https://github.com/GameTechDev/PresentMon) and the
[Gamers Nexus animation error methodology](https://gamersnexus.net/gpus-gn-extras-cpus/problem-gpu-benchmarks-reality-vs-numbers-animation-error-methodology-white).
What each term means, its other names (engines, platform libraries, Digital Foundry, older GPU reviews), where it comes from and
further reading are in **[mb-framepacing-explained](https://github.com/Unarmed1000/mb-framepacing-explained)**: its
[vocabulary](https://github.com/Unarmed1000/mb-framepacing-explained/blob/master/doc/vocabulary.md), with diagrams of the two
clocks behind animation error, and pages on
[vsync, VRR and frame rate targets](https://github.com/Unarmed1000/mb-framepacing-explained/blob/master/doc/display-sync.md),
[input latency](https://github.com/Unarmed1000/mb-framepacing-explained/blob/master/doc/input-latency.md),
[charts](https://github.com/Unarmed1000/mb-framepacing-explained/blob/master/doc/charts.md) and
[further reading](https://github.com/Unarmed1000/mb-framepacing-explained/blob/master/doc/further-reading.md).

This page only lists where each term appears in mb-framepacing.

| Term                       | In mb-framepacing                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Frame index**            | The application's counter of rendered frames, written into the marker (`frameIndex`); `frameIndex` (CSV). Unrelated to the capture index. Skipped indices are dropped frames, an index that goes back is out of order ([Filling the marker fields](marker-fields.md#frame-index))                                                                                                                                                                                                                                                             |
| **Run id**                 | Written into every marker of one test run (`runId`); `runs[].runId` (`summary.json`). Start and end markers with the same id bracket the measured frames                                                                                                                                                                                                                                                                                                                                                                                      |
| **Sequence id**            | 16 bytes in the start marker that identify the run (a UUID or a text tag); `runs[].sequenceId` (`summary.json`). The reports show it (below the name, when the capture has one)                                                                                                                                                                                                                                                                                                                                                               |
| **Animation error**        | `animationErrorTicks` (CSV), the Analyze page's error charts. Same formula and sign as PresentMon                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Animation time**         | Written into the marker by the application (the payload's animation time); `animationTicks` (CSV)                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Animation time step**    | `animationDeltaTicks` (CSV)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Display time**           | When a frame was first seen on screen: `firstSeenTicks` (CSV); the pacer's plan for it is `intendedDisplayTicks`                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Predicted display time** | When the game expects a frame to be shown, and animates it for: in the marker it is the **animation time**. Platforms give it (OpenXR `predictedDisplayTime`, Android Choreographer's expected presentation time, `CADisplayLink.targetTimestamp`)                                                                                                                                                                                                                                                                                            |
| **Intended display time**  | The time the frame pacer aims for a frame to be shown: the vsync it targets, the present time it requests (Vulkan `desiredPresentTime`, `VK_EXT_present_timing`, `EGL_ANDROID_presentation_time`) or a predicted display time it adopts. Written into the marker (the payload's intended display time); `intendedDisplayTicks` (CSV). Pacing and prediction error are measured from it                                                                                                                                                        |
| **Display time step**      | `displayDeltaTicks` (CSV), the display time step histogram                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Time on screen**         | `onScreenTicks` (CSV)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Frametime**              | From the markers: a frame's CPU start time to the next frame's (PresentMon's `MsBetweenAppStart`), `frameTimeTicks` (CSV), the Frametime panel                                                                                                                                                                                                                                                                                                                                                                                                |
| **CPU start time**         | Written into the marker by the application (the payload's CPU start time, PresentMon's `CPUStartTime`); `cpuStartTicks` (CSV)                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **CPU busy**               | Written into the marker: CPU start until Present (the payload's CPU busy, PresentMon's `MsCPUBusy`); `cpuBusyTicks` (CSV)                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **CPU wait**               | Frametime minus CPU busy (PresentMon's `MsCPUWait`); `cpuWaitTicks` (CSV)                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Frame pacing**           | The display time step histogram, late frames and the refresh strip (Timeline tab)                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Late frame**             | Shown half a refresh or more after its intended display time, or without a schedule half a refresh or more beyond its target: `Late` in the CSV `flags`, red                                                                                                                                                                                                                                                                                                                                                                                  |
| **Target frame time**      | The interval the pacer aims for now (a swap interval in time, which also covers VRR): the pacer's schedule, the marker's target, the marker's preferred frame time, `--target-fps`, else one refresh: `markerTargetTicks`, `targetTicks` (CSV); the dashed light grey line on the display time step and frametime panels                                                                                                                                                                                                                      |
| **Swap interval**          | How many refreshes a frame stays on screen before the next one: DXGI's `SyncInterval`, `eglSwapInterval`, Unity's `vSyncCount`. A target frame time of whole refreshes; the SDK's [frame pacer](pacer.md) (experimental) adapts it (`FrameSchedule.SwapInterval`)                                                                                                                                                                                                                                                                             |
| **Preferred frame time**   | The interval the application wants to run at, whatever its pacer manages (Apple's `preferredFramesPerSecond`, Unity's `Application.targetFrameRate`): written into the marker (the payload's preferred frame time); `markerPreferredTicks`, `preferredTicks` (CSV). The late share's amber: on screen longer than it without being late; the dashed amber line where it differs from the target                                                                                                                                               |
| **On demand**              | An application that presents only when something changes: target and preferred frame time `0xFFFFFFFF` in the marker. No frame of it is late for waiting                                                                                                                                                                                                                                                                                                                                                                                      |
| **Static frame**           | Nothing animates while it is on screen (an idle screen), whether or not it moved itself: the marker's `StaticAfter` flag on it or `StaticBefore` on the next frame, `StaticAfter` in the CSV `flags`. The step from it to the next frame is a **static step**: not judged, and the frame rate numbers leave it out (`StaticBefore` on the next frame, `excludedStaticFrames`). The step into it is judged. A rest whose flag a dropped frame took is **assumed** static (`StaticAssumed`, `analyze --no-static-guess` switches the guess off) |
| **Pacing error**           | With the pacer's schedule: display time step minus intended step, `pacingErrorTicks` (CSV)                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Prediction error**       | With the pacer's schedule: animation time step minus intended step, `predictionErrorTicks` (CSV)                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Stutter**                | Large animation errors                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Hitch**                  | A frame with a long display time step and a large negative animation error                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Short / long frame**     | Positive / negative animation error                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Delta time jitter**      | Animation errors while the display time step is even: the **Cause** line                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Microstutter**           | Display time step spread plus alternating animation errors                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Runt frame**             | Torn frames (the tearing check)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Judder**                 | Shows as a display time step spread and in the refresh strip                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Dropped frame**          | A frame the application rendered that never reached the display: a frame index skipped over a capture without gaps and never shown later (`skippedBefore` minus the frames shown out of order); orange in the display time step panel, the refresh strip and the events panel's frames lane. A frame index skipped across a capture gap is not called dropped: it may have been shown in the refresh the capture missed                                                                                                                       |
| **Out of order**           | A refresh that showed an older frame again after a newer one: `olderFrames` (CSV), pink in the refresh strip, the display time step panel and the events panel's frames lane                                                                                                                                                                                                                                                                                                                                                                  |
| **Capture gap**            | Captures not decoded, not recorded, dropped by the capture source (`sourceDropsBefore`) or missed without a word (`missedBefore`: the device clock's step): the display times around it are uncertain, so those steps are not judged (`UncertainStep`, `uncertainSteps`); dashed grey in the display time step panel, grey in the refresh strip and the events panel's capture lane                                                                                                                                                           |
| **Drift**                  | `driftTicks` (CSV), the Drift chart                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Tearing**                | Torn frames (the tearing check)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Input lag**              | Not measured                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

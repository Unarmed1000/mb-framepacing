# Vocabulary

mb-framepacing uses the vocabulary of [Intel PresentMon](https://github.com/GameTechDev/PresentMon) and the
[Gamers Nexus animation error methodology](https://gamersnexus.net/gpus-gn-extras-cpus/problem-gpu-benchmarks-reality-vs-numbers-animation-error-methodology-white),
which this project builds on. The same ideas go by other names in engines, platform libraries and older GPU reviews. The table
maps them, so a number from mb-framepacing can be compared with the others.

## Terms

| Term (as used here)     | Meaning                                                                                                                                                                                                                  | Other names                                                                                                                                                                    | Origin                                                                                                                                                                                                                                                           | In mb-framepacing                                                                              |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Animation error**     | How far the animation time advanced between two frames shown one after the other, minus how long the first of them was on screen. Positive: shown too soon (moved too far). Negative: shown too late (moved too little). | Simulation time error (Intel's earlier name); `MsAnimationError` (PresentMon CSV)                                                                                              | [PresentMon](https://github.com/GameTechDev/PresentMon/blob/main/README-ConsoleApplication.md#csv-columns); explained by [Gamers Nexus](https://gamersnexus.net/gpus-gn-extras-cpus/problem-gpu-benchmarks-reality-vs-numbers-animation-error-methodology-white) | `animationErrorMs` (CSV), the Analyze page's error charts. Same formula and sign as PresentMon |
| **Animation time**      | The moment of game time a frame shows, "the world at 12.345 s".                                                                                                                                                          | Simulation time, game time, animation timer; `AnimationTime` (PresentMon: usually the CPU start of the frame, or its simulation start with Reflex, XeLL or Anti-Lag 2)         | PresentMon, Gamers Nexus                                                                                                                                                                                                                                         | Written into the marker by the application (`animationTicks`); `animationMs` (CSV)             |
| **Animation time step** | How far the animation time advanced from one shown frame to the next.                                                                                                                                                    | Delta time, `Time.deltaTime` (Unity), timestep, CPU delta (PresentMon: "the previous frame's CPU delta")                                                                       | Engines ([Unity](https://unity.com/blog/engine-platform/fixing-time-deltatime-in-unity-2020-2-for-smoother-gameplay)), PresentMon                                                                                                                                | `animationDeltaMs` (CSV)                                                                       |
| **Display time**        | How long the previous frame stayed on screen before this one appeared.                                                                                                                                                   | Display delta, `MsBetweenDisplayChange` (PresentMon), display frame time. Overlays often call it "frame time", which PresentMon and Gamers Nexus keep for the CPU side (below) | PresentMon, Gamers Nexus                                                                                                                                                                                                                                         | `displayDeltaMs` (CSV), the display time histogram                                             |
| **On-screen time**      | How long this frame stayed on screen.                                                                                                                                                                                    | `DisplayedTime` (PresentMon)                                                                                                                                                   | PresentMon                                                                                                                                                                                                                                                       | `onScreenMs` (CSV)                                                                             |
| **Frametime**           | The time from the CPU starting one frame to starting the next: the application side, not the display.                                                                                                                    | `MsBetweenAppStart`, `MsBetweenPresents` (PresentMon, present to present), frame time, CPU frame time                                                                          | PresentMon, Gamers Nexus                                                                                                                                                                                                                                         | Not measured: the capture sees the display side; the animation time step stands in             |
| **Frame pacing**        | How evenly frames reach the screen.                                                                                                                                                                                      | Frame delivery, cadence. The [Android Frame Pacing library](https://developer.android.com/games/sdk/frame-pacing) (Swappy) uses it for syncing the render loop to the display  | Common usage; Android                                                                                                                                                                                                                                            | The display time histogram                                                                     |
| **Stutter**             | What the eye sees: motion that suddenly speeds up or slows down.                                                                                                                                                         | Judder, jerkiness, hitching                                                                                                                                                    | Common usage; Gamers Nexus describe it as visible acceleration or deceleration                                                                                                                                                                                   | Large animation errors                                                                         |
| **Hitch**               | A single, severe frametime spike.                                                                                                                                                                                        | Spike, long frame                                                                                                                                                              | Unreal Engine (`t.HitchFrameTimeThreshold`, see [Intel's Unreal Engine guide](https://www.intel.com/content/www/us/en/developer/articles/technical/unreal-engine-optimization-profiling-fundamentals.html)), Gamers Nexus                                        | A frame with a long display time and a large negative animation error                          |
| **Short / long frame**  | A frame shown sooner or later than the display rhythm expects. Short frames followed by long frames are seen as stutter.                                                                                                 | Frame shown too soon / too late                                                                                                                                                | [Android Frame Pacing library](https://developer.android.com/games/sdk/frame-pacing)                                                                                                                                                                             | Positive / negative animation error                                                            |
| **Delta time jitter**   | The engine's measured delta time varies while frames reach the screen evenly, so motion shakes slightly at a steady frame rate.                                                                                          | Timestep jitter, inconsistent `Time.deltaTime`                                                                                                                                 | [Unity 2020.2](https://unity.com/blog/engine-platform/fixing-time-deltatime-in-unity-2020-2-for-smoother-gameplay)                                                                                                                                               | Animation errors while the display time is even                                                |
| **Microstutter**        | Uneven frame delivery while the average frame rate looks fine. The term comes from multi-GPU (SLI/CrossFire) alternate frame rendering, with its "runt frames".                                                          | Micro stuttering, micro-stutter; uneven frame pacing                                                                                                                           | Multi-GPU era; [Wikipedia](https://en.wikipedia.org/wiki/Micro_stuttering), Gamers Nexus                                                                                                                                                                         | Display time spread plus alternating animation errors                                          |
| **Runt frame**          | A frame shown for only a sliver of a refresh, so it hardly counts for the eye while raising the frame rate.                                                                                                              | Partial frame                                                                                                                                                                  | Multi-GPU testing; Gamers Nexus                                                                                                                                                                                                                                  | Torn frames (the tearing check)                                                                |
| **Judder**              | Uneven display durations for content moving at a constant speed; also the jiggle in VR when frames miss the display.                                                                                                     | Stutter; pulldown judder (24p on 60 Hz)                                                                                                                                        | Video and film; VR ([Meta: Asynchronous Timewarp](https://developers.meta.com/horizon/blog/asynchronous-timewarp-on-oculus-rift/)); [Fora Soft](https://www.forasoft.com/learn/video-quality/articles-vqm/judder-stutter-frame-rate-artifacts)                   | Shows as a display time spread                                                                 |
| **Dropped frame**       | A frame that was rendered but never shown.                                                                                                                                                                               | Skipped frame; PresentMon reports `DisplayedTime` as "NA"                                                                                                                      | Common usage; PresentMon                                                                                                                                                                                                                                         | `skippedBefore` (CSV), counted in the report                                                   |
| **Drift**               | The difference between animation time and display time, accumulated over the run.                                                                                                                                        | Related: rubber-banding (Gamers Nexus: motion that stalls, then jumps ahead)                                                                                                   | mb-framepacing                                                                                                                                                                                                                                                   | `driftMs` (CSV), the Drift chart                                                               |

## The two ways animation error happens

Gamers Nexus explain it with a flipbook:

| Case                                                                                  | Flipbook                                        | Typical cause                                                                                  |
| ------------------------------------------------------------------------------------- | ----------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Frames reach the screen evenly, but the **animation time** advances unevenly          | Unevenly drawn pages, flipped at a steady tempo | Delta time jitter: the engine samples its clock at an uneven point in the frame                |
| The animation time advances evenly, but frames reach the screen unevenly (**pacing**) | Evenly drawn pages, flipped at an uneven tempo  | A frame over its budget shows a refresh late (a hitch); one submitted too early shows too soon |

Both give the same kind of number: how far each frame's motion is off from the time it was actually on screen.

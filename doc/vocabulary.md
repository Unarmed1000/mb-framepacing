# Vocabulary

mb-framepacing uses the vocabulary of [Intel PresentMon](https://github.com/GameTechDev/PresentMon) and the
[Gamers Nexus animation error methodology](https://gamersnexus.net/gpus-gn-extras-cpus/problem-gpu-benchmarks-reality-vs-numbers-animation-error-methodology-white).
What each term means, its other names (engines, platform libraries, Digital Foundry, older GPU reviews), where it comes from and
further reading are in **[mb-framepacing-explained](https://github.com/Unarmed1000/mb-framepacing-explained)**: its
[vocabulary](https://github.com/Unarmed1000/mb-framepacing-explained/blob/master/doc/vocabulary.md), with diagrams of the two
clocks behind animation error, and pages on
[vsync, VRR and frame rate targets](https://github.com/Unarmed1000/mb-framepacing-explained/blob/master/doc/display-sync.md),
[input latency](https://github.com/Unarmed1000/mb-framepacing-explained/blob/master/doc/input-latency.md),
[charts](https://github.com/Unarmed1000/mb-framepacing-explained/blob/master/doc/charts.md) and
[further reading](https://github.com/Unarmed1000/mb-framepacing-explained/blob/master/doc/further-reading.md).

This page only lists where each term appears in mb-framepacing.

| Term                       | In mb-framepacing                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Animation error**        | `animationErrorMs` (CSV), the Analyze page's error charts. Same formula and sign as PresentMon                                                                                                                                                                                                                                                                                          |
| **Animation time**         | Written into the marker by the application (`animationTicks`); `animationMs` (CSV)                                                                                                                                                                                                                                                                                                      |
| **Animation time step**    | `animationDeltaMs` (CSV)                                                                                                                                                                                                                                                                                                                                                                |
| **Display time**           | When a frame was first seen on screen: `firstSeenMs` (CSV); the pacer's plan for it is `intendedDisplayMs`                                                                                                                                                                                                                                                                              |
| **Predicted display time** | When the game expects a frame to be shown, and animates it for: in the marker it is the **animation time**. Platforms give it (OpenXR `predictedDisplayTime`, Android Choreographer's expected presentation time, `CADisplayLink.targetTimestamp`)                                                                                                                                      |
| **Intended display time**  | The time the frame pacer aims for a frame to be shown: the vsync it targets, the present time it requests (Vulkan `desiredPresentTime`, `VK_EXT_present_timing`, `EGL_ANDROID_presentation_time`, Swappy) or a predicted display time it adopts. Written into the marker (`intendedDisplayTicks`); `intendedDisplayMs` (CSV). Pacing and prediction error are measured from it          |
| **Display time step**      | `displayDeltaMs` (CSV), the display time step histogram                                                                                                                                                                                                                                                                                                                                 |
| **On-screen time**         | `onScreenMs` (CSV)                                                                                                                                                                                                                                                                                                                                                                      |
| **Frametime**              | From the markers: a frame's CPU start time to the next frame's (PresentMon's `MsBetweenAppStart`), `frameTimeMs` (CSV), the Frametime panel                                                                                                                                                                                                                                             |
| **CPU start time**         | Written into the marker by the application (`cpuStartTicks`, PresentMon's `CPUStartTime`); `cpuStartMs` (CSV)                                                                                                                                                                                                                                                                           |
| **CPU busy**               | Written into the marker: CPU start until Present (`cpuBusyTicks`, PresentMon's `MsCPUBusy`); `cpuBusyMs` (CSV)                                                                                                                                                                                                                                                                          |
| **CPU wait**               | Frametime minus CPU busy (PresentMon's `MsCPUWait`); `cpuWaitMs` (CSV)                                                                                                                                                                                                                                                                                                                  |
| **Frame pacing**           | The display time step histogram, late frames and the refresh strip (Timeline tab)                                                                                                                                                                                                                                                                                                       |
| **Late frame**             | Shown half a refresh or more after its intended display time, or without a schedule half a refresh or more beyond its target: `Late` in the CSV `flags`, red                                                                                                                                                                                                                            |
| **Target frame time**      | The interval the pacer aims for now (a swap interval in time, which also covers VRR): the pacer's schedule, the marker's target, the marker's preferred frame time, `--target-fps`, else one refresh: `markerTargetMs`, `targetMs` (CSV)                                                                                                                                                |
| **Preferred frame time**   | The interval the application wants to run at, whatever its pacer manages (Apple's `preferredFramesPerSecond`, Unity's `Application.targetFrameRate`): written into the marker (`preferredFrameTicks`); `markerPreferredMs`, `preferredMs` (CSV). The late share's amber: on screen longer than it without being late                                                                    |
| **On demand**              | An application that presents only when something changes: target and preferred frame time `0xFFFFFFFF` in the marker. No frame of it is late for waiting                                                                                                                                                                                                                                |
| **Static frame**           | Nothing animates in it (an idle screen): the marker's `Static` flag, `Static` in the CSV `flags`. The animation error of a step from or to it is not judged, and the frame rate numbers leave out its time on screen (`StaticBefore` on the next frame, `excludedStaticFrames`)                                                                                                         |
| **Pacing error**           | With the pacer's schedule: display time step minus intended step, `pacingErrorMs` (CSV)                                                                                                                                                                                                                                                                                                 |
| **Prediction error**       | With the pacer's schedule: animation time step minus intended step, `predictionErrorMs` (CSV)                                                                                                                                                                                                                                                                                           |
| **Stutter**                | Large animation errors                                                                                                                                                                                                                                                                                                                                                                  |
| **Hitch**                  | A frame with a long display time step and a large negative animation error                                                                                                                                                                                                                                                                                                              |
| **Short / long frame**     | Positive / negative animation error                                                                                                                                                                                                                                                                                                                                                     |
| **Delta time jitter**      | Animation errors while the display time step is even: the **Cause** line                                                                                                                                                                                                                                                                                                                |
| **Microstutter**           | Display time step spread plus alternating animation errors                                                                                                                                                                                                                                                                                                                              |
| **Runt frame**             | Torn frames (the tearing check)                                                                                                                                                                                                                                                                                                                                                         |
| **Judder**                 | Shows as a display time step spread and in the refresh strip                                                                                                                                                                                                                                                                                                                            |
| **Dropped frame**          | A frame the application rendered that never reached the display: a frame index skipped over a capture without gaps and never shown later (`skippedBefore` minus the frames shown out of order); orange in the display time step panel and the refresh strip. A frame index skipped across a capture gap is not called dropped: it may have been shown in the refresh the capture missed |
| **Out of order**           | A refresh that showed an older frame again after a newer one: `olderFrames` (CSV), pink in the refresh strip and the display time step panel                                                                                                                                                                                                                                            |
| **Capture gap**            | Captures not decoded, not recorded, or dropped by the capture source: the display times around it are uncertain, so those steps are not judged (`UncertainStep`, `uncertainSteps`); dashed grey in the display time step panel, grey in the refresh strip                                                                                                                               |
| **Drift**                  | `driftMs` (CSV), the Drift chart                                                                                                                                                                                                                                                                                                                                                        |
| **Tearing**                | Torn frames (the tearing check)                                                                                                                                                                                                                                                                                                                                                         |
| **Input lag**              | Not measured                                                                                                                                                                                                                                                                                                                                                                            |

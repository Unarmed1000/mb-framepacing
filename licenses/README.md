# Third-party licenses

mb-framepacing itself is licensed under two licenses by path, see [`../LICENSE`](../LICENSE) for the exact list: the BSD
3-Clause License for the frame marker libraries (`cpp/`), their documentation and golden marker images, and the
PolyForm Perimeter License 1.0.1 for everything else.

This directory holds the license text of **every** third-party component the project uses, whether it is vendored, downloaded by a
package manager, fetched at build time or only used by tests. When you add a dependency, add its license file and a row below in the
same change.

"Shipped" means the component ends up in a binary we distribute: the `mb_framemarker` static library (and anything linking it) or the
`mb-framepacing` / `mb-framepacing-gui` tools.
